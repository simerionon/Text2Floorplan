# 校准后的样例

[English](README.md)

本目录并列保留独立网页工作站和 Revit 插件的样例。网页中点击 **导入样例**
加载 `plan.json`，或点击 **打开 JSON** 查看本目录任一 JSON，无需运行模型。
命令行新生成的 JSON 也可直接在工作站中编辑，见 [推理指南](../docs/inference.zh.md)。
Revit 插件通过自己的生成命令创建原生构件，当前没有单独导入编辑后 JSON 的命令。

两张图和 `plan.json` 使用同一份户型数据，保留种子 `3968430468`，
采用当前 large 比例 **0.05466578730522668 米/画布单位**。
扣除墙体占地、包含阳台的总净面积为 **128.9㎡**。

提示词：`A large 3-bedroom apartment with 2 bathrooms and 2 balconies.`

客厅 49.1㎡，厨房 10.8㎡，三个卧室分别为 16.0、21.2、14.3㎡，
两个卫生间分别为 3.9、2.7㎡，两个阳台分别为 3.0、7.7㎡。
总面积使用未舍入数值计算。共有 28 段墙、9 扇门、4 扇窗、5 段阳台栏杆。
外墙厚 400 mm，内墙厚 200 mm，墙高 3.3 m。

- `floorplan.png`：重新绘制的二维平面图，包含各房间及总净面积。
- `model3d.png`：网页 WebGL 渲染器导出的 2048 × 1536 三维图，
  与平面使用相同数据，保留真实门窗洞口及开放式阳台栏杆。
- `model-metadata.json`：当前比例、面积、构件数量和验证范围。

相交墙面补齐直角，墙中线仍可独立编辑。门窗宽度随新版水平比例更新；
墙厚、墙高、门窗高度和窗台高度保持原来的米制数值。

新版图片来自本地网页编辑器，未重新进行 Revit 原生导出和面积验证。
原来的 106.2㎡原生 Revit 样例也在本目录保留，见下方。
JSON 保留 Revit 输入格式；门窗布置规则、面积及地面网格已通过检查。

## Revit 原生样例

`revit-floorplan.png` 和 `revit-model3d.png` 为原先 Revit 2022 的真实导出图，
总净面积为 106.2㎡。`revit-plan.json` 为对应输入，`revit-metadata.json` 保留
原生面积及构件数量。网页版和 Revit 版样例并列保留；当前 128.9㎡的网页样例
采用后来更新的比例，两份记录分别标明来源。
