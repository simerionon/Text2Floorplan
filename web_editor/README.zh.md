# 文字生成户型图（Text2Floorplan）— 本地浏览器编辑器

[English](README.md)

使用现有本地模型生成户型，编辑二维房间角点，并同步查看三维墙体、门窗和
阳台栏杆。编辑器本身不依赖 Revit。默认英文，可在右上角切换中文；提示词
继续使用项目支持的英文格式。

这是独立的 **网页工作站**，有自己的启动器和运行环境。Revit 用户另用
`text2floorplan_revit-Setup.exe` 安装插件，两版均不要求安装另一版。
生成使用本地 CLIP 和 Flow Matching，无需 LLM、API Key 或云端推理服务。

## 完整 Windows 网页版

发行版自带 Python、PyTorch、CLIP 和训练权重。按 [Windows 包说明](PORTABLE.zh.md)
下载主 ZIP 及全部数据 ZIP 到同一位置，只解压主 ZIP，双击
`Start-Text2Floorplan.cmd`。启动器自动选择空闲端口，不需要安装 Revit 或 Python。
同时会生成完整离线 ZIP，供通过其他下载地址分发。

## 从源码启动

Windows 下双击 **`web_editor/Start-Editor.cmd`**，保持打开的控制台窗口运行。
关闭窗口或按 Ctrl+C 即可停止本地程序。默认端口被占用时，可以从终端启动
并传入 `--port 8768`。

启动器依次检查 `TEXT2REVIT_PYTHON`、名为 `Text2Revit` 的本地 Conda 环境、
已安装的 Revit 插件版 Python 环境，以及 PATH 中的 `python`。源码启动器复用
已有环境，不自动安装依赖；上方完整 Windows 网页版自带运行环境。

也可以在仓库根目录运行：

```powershell
python -m pip install -r requirements.txt
python scripts/setup_models.py
python -m web_editor.server --open
```

另需提供兼容的完整或精简 PTH，模型路径及 CPU 设置见
[推理指南](../docs/inference.zh.md)。也可先通过 `python infer.py --prompt "..."`
直接生成，再将输出 JSON 在工作站中打开。

英文版：`http://127.0.0.1:8765/en`；中文版：`http://127.0.0.1:8765/zh`。
根路径 `/` 默认英文，页内切换语言会同步修改网址并保留当前模型。也可在
启动命令中加 `--language zh --open`，直接打开中文版。

页面首次打开时画布和提示词均为空。生成户型或打开 JSON 后才显示模型；
调试时点击 **导入样例**，手动载入内置 sample，不需要加载训练权重。编辑需要 NumPy 和 Shapely；推理还需要 `requirements.txt` 中的
依赖及训练权重、CLIP 编码器，准备方式见主 README。编辑器可复用已安装的
Text2Revit 模型，也支持指定路径：

```powershell
python -m web_editor.server --open --python C:/Python/python.exe --checkpoint C:/Models/flow_matching_best.pth --clip-dir C:/Models/clip
```

## 提示词格式

`A (large / small / none = default) n-bedroom apartment with n bathrooms and n balconies.`

n 替换为所需数量。大小只写 `small` 或 `large`；默认中户型省略大小词，
不要把 `none` 写入实际提示词。页面提供三个可点击的示例：

- `A small 2-bedroom apartment with 1 bathroom and 1 balcony.`
- `A 3-bedroom apartment with 2 bathrooms and 1 balcony.`
- `A large 4-bedroom apartment with 2 bathrooms and 2 balconies.`

点击示例只填入输入框，点击 **生成户型** 或在提示词框按 Enter 才开始推理。

## 操作

- 在二维图中选房间，拖动其角点。X 沿相连竖向房间边界传播，Y 沿横向边界传播，
  共享墙和 T 形交点同步更新；拖动按 100 mm 吸附。角点获得焦点后，也可
  用方向键按 100 mm 微调。
- 相交墙面在偏移线交点连接，补齐外角，同时保留两条墙中线独立编辑。
  孤立墙端保持平头，不会自动跨过可见断口；二维、三维和面积计算共用连接几何。
  两段外墙转角上再接入内墙时，仍保留外墙的完整转角；墙厚差产生的正常台阶不调整。
- 选择墙体，修改墙高、墙厚，或直接输入毫米制 X／Y 位移。
- 房间还提供边和中心控制柄。拖边只垂直移动这条边，拖中心平移整个房间；
  相邻房间边界保持连接。对已闭合房间的显式编辑会调整实际边界墙节点；
  未闭合、合并、分隔或带洞空间请通过单独墙段编辑。
- 选择墙后，二维和三维立即同时显示两端圆点及中心方点，无需在右侧切换模式。
  拖端点只移动这一端，另一端固定，可形成斜墙；拖中心方点平移整段墙及其
  门窗。中心拖动区域只限方点，不覆盖端点。其他墙段保持原位，房间边界及
  面积重新计算；精确毫米制 X／Y 位移输入仍保留。栏杆同样提供三个控制柄。
- 整段移动保留门窗尺寸；端点移动使门窗随墙转向，并保持它们距固定端
  的实际距离。不能把墙缩成零长度，也不能缩短到容不下原有门窗。
- 门窗在二维提供两端和中心，在三维及属性栏正立面中提供四边及中心。
  中心移动整块并保持宽高；左右边改变宽度，上下边改变高度，对边保持
  固定。在二维或三维拖中心方点可换到另一面墙，预览自动随目标墙转向，
  松开后同步更新宿主、所属房间和门洞，原墙恢复。须落在有效放置点 600 mm
  内，门窗完整放入墙段、两端至少余 25 mm，且不与其他门窗冲突；窗和入户门
  只能放在外墙。宽高及离地高度保持不变。门另提供 **翻转开门方向** 和
  **交换铰链侧**，二维、三维及保存重开均保留。转角换墙时随墙角度旋转，
  门洞保持附着墙体。属性栏正立面中心仍沿当前墙及上下移动，垂直位移改变窗台高／离地高度。不能低于地面
  或超过墙顶，门初始从地面起算。数值输入也可修改相同参数。
- 拖动时显示轮廓预览，松开后提交一次修改。二维、三维默认开启节点吸附：12 像素内优先命中端点或交点，
  8 像素内可投影到墙线形成 T 形连接，整段吸附保持形状。点击 **吸附** 或
  按 S 切换；按住 Alt 临时关闭节点和网格吸附，其他位置按 100 mm 网格移动；控制柄获得
  焦点后可用方向键微调。门窗正立面控制柄的左右键沿墙、上下键沿高度方向；
  二维／三维中心点使用平面 XY 位移。三维看不清时可旋转／放大，或使用正立面编辑。
- 选择栏杆，修改栏杆高度。阳台外边缘保持开放。
- 二维图左键拖动空白处即可平移。选择 **平移** 工具（H）后，可在房间上
  拖动；也可按住空格临时平移。**选择**（V）恢复构件及角点编辑，右键／
  中键拖动同样支持平移。滚轮或 +/− 缩放，**适应** 显示完整户型。
- 顶部可切换 **二维平面**、**双视图**、**三维模型**。三维拖动旋转、滚轮
  缩放，点击构件查看属性；**俯视** 从上方查看，**重置视角** 恢复透视，**保存 PNG** 导出当前视角的 2048 × 1536 三维图。
- 撤销、重做用于已接受的修改；焦点不在输入框内时，也支持 Ctrl+Z 和
  Ctrl+Shift+Z。
- **Save model／保存模型** 下载当前可编辑模型；**Open JSON／打开 JSON**
  重新打开 schema 1.0 的 Text2Revit 文件。刷新页面会清空未保存修改，
  关闭或刷新前请保存。

自由墙的位置在保存、重开和修改参数后保留，不会从旧房间多边形重新生成。
编辑后按当前墙线及阳台栏杆识别封闭区域，扣除墙体占地，重算房间及总净面积；
二维填色、面积标签和三维地面同步更新，支持斜墙和带洞区域，包含阳台面积。

墙线断开时，房间显示 **未闭合**，不沿用旧面积；总面积标注为部分面积，
只计算已闭合区域。把墙节点吸附接回后恢复面积。合并区域只计一次总面积，
分隔或未命名区域单独报告，不虚构原房间的面积。房间控制柄仅用于唯一匹配、
无洞的闭合房间，其余情况通过墙段编辑。

房间面积低于生成最低值时只提示。非法房间多边形、门窗
脱离宿主或尺寸越界，会拒绝修改；同墙门窗仍检查间距，自由编辑后跨墙
门窗间距冲突改为提示；直接移动门窗时仍严格拒绝跨墙间距冲突。模型推理
仍保留原来的严格生成检查。

**Generate layout／生成户型** 使用现有 `backend_cli.py` 在本地 Python
进程中推理，底部显示进度，**Cancel／取消** 可终止该推理进程。一次运行
一个任务，输入、日志和生成结果保存在已被 Git 忽略的
`outputs/web_editor/<job-id>/`。

## 首版范围

这是单用户本地网页工作站，仅监听 `127.0.0.1`，尚不用于公网部署。前端全部使用
本地资源，不依赖 CDN、Node.js 构建或浏览器版 PyTorch；模型推理仍在本机
Python 后端运行，并沿用其 GPU／CPU 行为。

三维界面根据可编辑数据生成墙体实体、真实洞口、窗框、门扇、地面和栏杆，
与二维图共用同一份数据。目前支持闭合房间边界编辑、独立斜墙、节点吸附和墙体围合面积重算，还不支持
新增／删除房间、任意绘制新墙、多楼层、Revit 族编辑、IFC／GLB 导出或协作。

保存的 JSON 保留现有 Revit 输入格式，但首版不直接写 `.rvt`，也尚未为
Revit 新增“导入编辑后的 JSON”命令。原生 Revit 输出仍需插件，导入命令
可作为后续独立步骤实现。

程序结构及检查命令见 [英文说明](README.md)。后续可以把同一前端封装为
桌面小软件，复用现在的可编辑模型接口和推理后端。
